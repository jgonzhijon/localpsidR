# localpsidR

localpsidR is a package that helps the task of building longitudinal
datasets from the Panel Study of Income Dynamics (PSID). The user must
supply the PSID variable names that correspond to the variables of
interest in each desired wave. Data can be supplied via Stata, or
directly downloaded from PSID servers without any need for STATA.
data.frame.
